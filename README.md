# Google Apps Script ルーレット

項目ごとに音声を設定し、円形ルーレットを実行するWebアプリです。フロントエンドはHTML/CSS/JavaScript、バックエンドはGoogle Apps Script（GAS）で構成します。各実行で音声と `manifest.json` をアプリ所有者のGoogle Driveに非公開で保存します。

## 必要なファイル

- `Code.gs`：ウェブアプリ、入力検証、実行制限、Driveへの保存処理
- `index.html`：項目・音声管理、ルーレット画面
- `css/styles.css`：画面スタイル
- `js/app.js`：画面の操作とGAS連携

## Google Apps Scriptへの配置と公開

1. Google Driveに音声保存用の親フォルダを作成し、フォルダIDを控えます。フォルダIDはフォルダURLの `/folders/` の後ろの文字列です。
2. [Google Apps Script](https://script.google.com/)で新しいプロジェクトを作成します。
3. プロジェクトのスクリプトファイルに `Code.gs` の内容を配置します。
4. HTMLファイル `index` を追加し、`index.html` の内容を配置します。
5. HTMLファイル `styles` を追加し、`css/styles.css` の内容を配置します。
6. HTMLファイル `app` を追加し、`js/app.js` の内容を配置します。GASプロジェクトにはフォルダを作らず、これらのHTMLファイル名を `index.html` のinclude名に合わせます。
7. `Code.gs` の `PARENT_FOLDER_ID` を手順1のIDに置き換えます。実際のフォルダIDや秘密情報はソース管理へ登録しないでください。
8. `TIME_ZONE` を運用するタイムゾーンに設定します。初期値は `Asia/Tokyo` です。
9. エディタから `setup()` を一度実行し、表示された権限確認を承認します。親フォルダへのアクセス確認で失敗した場合はIDと実行アカウントの権限を確認してください。
10. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」を選択します。
11. 実行ユーザーはDrive保存先の所有者（自分）に設定します。アクセスできるユーザーは必要な範囲に制限してください。
12. デプロイして発行されたウェブアプリURLを利用者に共有します。別ブラウザ／ログアウト状態でもアクセス可能か確認してください。

組織のGoogle Workspace設定やGoogleの公開ポリシーにより、匿名利用や「全員」への公開が許可されない場合があります。設定制限を回避せず、組織の管理者と利用可能な公開方式を確認してください。

## 使い方

1. 項目名を入力し、必要なら音声を選択して追加します。既存項目の編集、削除、音声の差し替え・解除、試聴ができます。
2. 一括登録では最大5ファイルを選択またはドロップし、既存項目または新規項目への割り当てを確認・変更して登録します。ファイル名と項目名が一致する場合は候補を自動選択します。
3. 項目を2件以上登録して「ルーレットを回す」を押します。
4. サーバーが保存先の実行フォルダを作り、音声を保存した後にルーレットが回転します。完了後、当選結果を画面に表示し、対応する音声を再生します。

項目と選択中の音声ファイルはブラウザ上で保持され、ページを再読み込みすると消えます。各実行で使用した音声と実行時点の項目・当選結果はDriveのmanifestに保存されます。設定一覧をブラウザ間で同期する機能はありません。

## 保存内容と形式制限

実行フォルダは `親フォルダ/年/月/日/時/分/秒/run_実行ID/` の階層に作成されます。年月日時分秒のフォルダは再利用し、各実行ではUUIDベースの異なるフォルダを作成します。フォルダ・ファイルは共有設定を追加せず、Drive上で非公開のまま保存します。

- 音声形式：MP3、WAV、OGG、M4A、AAC、WebM、FLAC。ファイル拡張子とブラウザが返すMIMEタイプの両方を確認します。MIMEタイプを取得できない環境や、ブラウザ／GASで扱えない形式は拒否される場合があります。
- 最大サイズ：1ファイル5MB、1実行5ファイル、合計15MB。
- 項目数は1実行につき最大100件です。
- ファイル名はDrive上では `audio-01.mp3` のようなサーバー生成名になります。元ファイル名はmanifest内の表示情報として記録されます。
- manifestには実行ID、開始・終了時刻、タイムゾーン、項目と音声ファイルの対応、当選項目を記録します。認証情報は記録しません。
- `beginSpin` 発行のトークンは30分で失効し、別の実行フォルダへのアップロードには使用できません。
- 音声アップロードやmanifest保存に失敗した場合、その実行は画面に失敗を表示します。途中まで保存された実行フォルダや音声は自動削除されないため、必要に応じてDriveで確認・整理してください。

## 濫用対策と制約

初期設定はスクリプト全体で1日最大100実行、実行開始の間隔15秒以上です。GASの匿名アクセスでは、強固な利用者識別やIP単位のレート制限を保証できません。これらの上限・クールダウンはこのGASデプロイ全体で共有されるため、利用者が多い場合は正当な実行も制限されます。Google Apps ScriptとDriveの実行クォータも適用されます。

Driveの実データ、公開設定、匿名ユーザーからの利用可否は、所有者のGoogleアカウントとデプロイ設定に依存します。実際のGoogleアカウントを使った `setup()`、デプロイ、別ブラウザからのアクセス、Drive保存は、プロジェクト所有者が確認してください。

## テストとローカル確認

このリポジトリにはGASの実行環境や自動テスト基盤は含まれていません。ブラウザの `google.script.run` はGASウェブアプリ内でのみ利用できるため、通常のローカルHTTPサーバーではバックエンド連携を確認できません。公開前に次を実環境で確認してください。

- 項目の追加・編集・削除、音声の解除、プレビュー、一括割り当てと登録
- 1件以下での実行拒否、音声なし／あり項目の当選と停止位置の一致
- 不正形式、5MB超、5ファイル超、合計15MB超の拒否
- 実行連打、実行クールダウン、日次上限、トークン期限切れ
- 音声保存、`manifest.json`、同一秒の複数実行、結果とmanifestの一致
- Drive権限エラー時の表示、保存ファイルが非公開であること
- 別ブラウザからウェブアプリを利用できること
